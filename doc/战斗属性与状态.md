# 战斗属性与状态

## Combat Attribute Set

Combat Attribute Set 是 GAS 中保存角色战斗数值的对象。它不负责 Combo，也不负责播放攻击动画。

第一版属性：

```text
Health
MaxHealth
AttackPower
Defense
Poise
```

属性规则：

```text
Health >= 0
Health <= MaxHealth
MaxHealth > 0
Defense >= 0
Poise >= 0
```

## 层间规则

- GAS 保存和复制属性。
- AngelScript 读取属性并决定规则。
- AngelScript 不直接写 Health。
- 伤害和状态修改通过 C++ Bridge 进入 GAS。
- C++ 负责服务器权限和数值边界校验。

## 属性变化流程

```text
GameplayEffect
 -> AttributeSet
 -> 属性边界校验
 -> OnAttributeChanged
 -> AngelScript ReactionPolicy
```

## 最小验收

- 创建角色后 Health 等属性有默认值。
- Health 不会低于 0。
- 伤害可以修改 Health。
- Health 为 0 时添加 `State.Dead`。
- `State.Dead` 存在时不能开始 CommonAtk。
