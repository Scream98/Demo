```text
## 临时方案验收

1. 用 `ACS` 或其蓝图子类作为主角放入 PIE。
2. 按鼠标左键，日志应出现 `CommonAtk_01` 的播放动画和阶段日志。
3. 在 Combo 阶段再次按左键，依次观察 `CommonAtk_02`、`CommonAtk_03`。
4. 用 `ACombatMonsterCharacter` 创建临时 BP 后放入地图，确认它不响应鼠标左键。
5. 从 AI、控制台或脚本调用 `RequestCommonAtkInput()`，确认怪物仍能复用同一套三段攻击。
6. 观察 BeginPlay 日志中的 `CharacterId`、`Faction`、`Profile`、`AbilitySet`。

当前未完成：正式角色基类迁移、真实动画 Montage、打击帧、命中检测、伤害和受击反应。临时 BP 和 `BattleMap` 测试实例已经通过 UE MCP 创建并编译。
```
