# 战斗输入与动画

## 输入资源

创建：

```text
IA_CommonAtk
IMC_Combat
```

默认绑定：

```text
鼠标左键 -> CommonAtk
手柄 RB   -> CommonAtk
```

现有 `Content/Script` 为 UnLua Lua 目录，AngelScript 战斗代码使用 `Demo/Script/Combat`。

当前临时输入直接使用 `Config/DefaultInput.ini`：

```text
鼠标左键 -> CommonAtk
W/A/S/D  -> 移动
```

主角 `ACS` 在 `SetupPlayerInputComponent` 中绑定 `CommonAtk`。`ACombatMonsterCharacter` 不绑定玩家输入，AI/脚本可以调用 `RequestCommonAtkInput()` 触发同一套 Ability。

## 动画事件

当前没有接入攻击动画时，`PlayAttackAnimation()` 只输出日志：

```text
[Combat] CommonAtk_01 PlayAnimation AttackId=CommonAtk_01 AnimationId=002000
```

阶段由临时计时器模拟，时长位于 `CombatScriptBridge` 的可重载配置中。接入 Montage 后，再把阶段推进替换为 Notify，不改变输入和 Ability 接口。

每个攻击动作需要：

```text
AttackBegin
AttackHit
AttackEnd
ComboWindowOpen
ComboWindowClose
```

正式时序以 AnimNotify 为准，固定时间仅作为无动画资源时的测试 fallback。

## 动作选择

AngelScript 根据以下信息选择动作：

```text
AttackId
WeaponType
MovementDirection
ComboIndex
EldenAnimationId
```

动作编号、动画路径和 Montage Section 分开保存，不能把资源路径写死在 Combo 状态机中。

## 资源验证顺序

1. 确认 c0000 Skeleton。
2. 确认动作资源类型。
3. 确认动画时长。
4. 确认攻击帧。
5. 创建或配置 Montage。
6. 添加 AnimNotify。
7. 接入 CommonAtk AbilityGroup。
