# 攻击命中检测模块

## 目标

由 C++ 执行稳定的物理查询，由 AngelScript 编辑目标过滤和命中后的战斗规则。

## 查询参数

```text
HitRange
HitRadius
HitHeight
HitChannel
HitOffset
bAllowMultiHit
```

第一版查询：

```text
Start = ActorLocation + HitOffset
End = Start + ForwardVector * HitRange
Shape = Sphere 或 Capsule
Channel = Pawn
```

## C++ 负责

- 执行 `SweepMultiByChannel`。
- 忽略攻击者自身。
- 过滤无碰撞组件。
- 将命中转换为 `FCombatHitResult`。
- 保障查询只在有效攻击窗口执行。

## AngelScript 负责

```text
ShouldDamageTarget(Target)
GetDamageForTarget(Target, HitResult)
OnHitConfirmed(HitResult)
```

## 去重

每个攻击步骤维护：

```text
DamagedActors
```

同一攻击步骤中，同一个 Actor 默认只受到一次伤害。需要多段伤害时由该攻击步骤显式打开 `bAllowMultiHit` 并配置间隔。

## 验收

- 不命中自身。
- 命中 TargetDummy。
- 同一目标不重复受伤。
- 可以命中多个目标。
- 攻击窗口外不产生查询。
- 目标没有战斗组件时安全跳过。
