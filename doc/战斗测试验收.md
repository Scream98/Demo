# 战斗测试与验收

## 脚本编译

- 所有 Combat `.as` 文件可编译。
- AngelScript 类型、继承和 UE 函数调用正确。
- 热重载后没有残留旧的攻击状态。

## 属性和伤害

- Health、MaxHealth、AttackPower、Defense、Poise 初始化正确。
- Health 不低于 0 且不超过 MaxHealth。
- 基础伤害和 Defense 减伤正确。
- DefenseIgnore 正确生效。
- 无敌目标不受伤害。
- Health 归零只触发一次死亡。

## 命中

- 攻击者不会命中自己。
- TargetDummy 可以被命中。
- 同一攻击步骤不会重复伤害同一目标。
- 多目标攻击可以命中多个目标。
- 攻击窗口外不执行 Sweep。

## Combo

- 单次输入播放第一段。
- 窗口内连续输入完成三段。
- 窗口外输入不会跳段。
- 快速多次输入不会跳过步骤。
- 第三段结束后回到 Idle。
- 受击、硬直、翻滚和死亡会清空 Combo。

## 编辑器和 PIE

- UE 5.8 编辑器正常加载。
- AngelScript 无启动脚本错误。
- 主地图和测试地图可以运行。
- 动画资源缺失时不崩溃。
- 日志无 Fatal、脚本编译错误或模块加载错误。
