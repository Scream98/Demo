# 战斗伤害模块

## 目标

让伤害公式、伤害类型和目标修正可以直接在 AngelScript 中编辑，最终属性修改仍由 C++/GAS 执行。

## 输入

```text
Attacker
Target
AttackId
BaseDamage
AttackPowerScale
DefenseIgnore
PoiseDamage
DamageTags
```

## AngelScript 计算

```text
RawDamage = BaseDamage + AttackPower * AttackPowerScale
FinalDamage = max(0, RawDamage - Defense * (1 - DefenseIgnore))
```

脚本输出：

```text
FCombatDamageRequest
├── Source
├── Target
├── AttackId
├── DamageAmount
├── PoiseAmount
├── DamageTags
└── HitResult
```

## C++/GAS 执行

```text
ApplyDamage(DamageRequest)
 -> 校验 Source/Target
 -> 校验服务器权限
 -> 检查 State.Invincible
 -> 构造 GameplayEffectSpec
 -> 修改 Health 和 Poise
 -> 广播伤害事件
```

## 规则

- 目标无效或已死亡时不处理。
- 攻击者不能伤害自己。
- 无敌状态忽略伤害。
- 最终伤害不能小于 0。
- 同一次攻击对同一目标只结算一次。
- Health 归零后只触发一次死亡事件。

## 测试

- 基础伤害计算。
- Defense 减伤。
- DefenseIgnore 生效。
- 零伤害和负伤害钳制。
- 无敌目标过滤。
- 多目标伤害。
- Poise 伤害触发硬直。
