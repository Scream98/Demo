# 战斗受击与中断

## 中断来源

```text
HitReact
Stunned
Knockdown
Dead
Dodge
ManualCancel
```

## 优先级

```text
Dead > Knockdown > Stunned > HitReact > Dodge > ManualCancel
```

## 中断流程

```text
收到中断
 -> 判断优先级
 -> 停止当前 Montage
 -> 清空 Combo 输入
 -> 清空命中缓存
 -> 移除 State.Attacking
 -> 添加受击或硬直标签
 -> 播放反应动画
 -> 广播 OnAttackInterrupted
```

## 受击判断

- Health 归零进入 `State.Dead`。
- Poise 归零进入 `State.Stunned` 或 `State.Knockdown`。
- 无敌状态不进入受击流程。
- 死亡状态不重复播放受击动画。
- 受击结束后由 AngelScript 决定是否恢复 Idle。

## 验收

- 攻击中受到命中可以中断 Combo。
- 中断后下一次攻击从第一段开始。
- 死亡时清理所有攻击状态。
- 高优先级状态覆盖低优先级状态。
